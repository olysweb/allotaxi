## ✨ À propos du projet

**Allo Taxi** est un groupe de plusieurs sites vitrines conçues pour **présenter les services** de taxi de l'entreprise et **faciliter la prise de contact**.

Ce projet a été imaginé dans une logique de plusieurs **sites vitrines** simples, modernes et dynamiques, permettant un référencement naturel optimal (SEO) de l'entreprise.

---

## 🎯 Objectifs

* Présenter les services
* Faciliter la prise de contact
* Améliorer le référencement naturel (SEO)

---

## 🧠 Approche technique

Ce projet a été développé avec une attention particulière portée à :

* 🔎 La navigation
* 📱 L’accessibilité et le responsive design
* 📈 L'évolution et la maintenabilité

---

## 🛠️ Stack technique

### Frontend

* HTML5
* CSS3
* SASS
* JS léger (animation menu de navigation)

### API

* Formspree (pour l'envoi sécurisé du formulaire de contact)

### Outils

* Git / GitHub
* VS Code
